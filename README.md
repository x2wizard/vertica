# GTG Vertica 블로그

버티카(OpenText Analytics Database)에 대한 정보를 나누는 블로그입니다.
[Astro](https://astro.build) + [Starlight](https://starlight.astro.build)로 만들었습니다.

```bash
npm install
npm run dev      # http://localhost:4321/vertica/
npm run build && npm run check-links
```

자세한 구조와 규칙은 [CLAUDE.md](./CLAUDE.md)를 참고하세요.
