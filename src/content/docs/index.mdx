## Vertica 핵심 기술 요소

<div class="core-tech">
  <Image src={coreTech} alt="Vertica 데이터베이스 엔진 4대 기술 요소" />
  <dl>
    <dt>Massively Parallel Processing (MPP)</dt>
    <dd>별도의 마스터 노드 없이 모든 노드에서 병렬로 쿼리를 실행합니다. 선형적으로 scale-out하여 더 빠른 성능 또는 더 많은 사용자를 지원합니다.</dd>
    <dt>Columnar Storage</dt>
    <dd>필요한 데이터만 읽어 기존 ROW 기반 스토리지 시스템에 비해 쿼리 속도가 빠릅니다.</dd>
    <dt>Advanced Compression</dt>
    <dd>컬럼별 고급 압축 알고리즘과 인코딩으로 저장 공간을 최대 90%까지 줄이고, 쿼리 수행 시 디스크 I/O 비용이 줄어 성능이 향상됩니다.</dd>
    <dt>Optimized Projections</dt>
    <dd>Projection이라는 최적화된 형식과 구조로 데이터를 저장하여 인덱스가 필요 없습니다.</dd>
  </dl>
</div>
